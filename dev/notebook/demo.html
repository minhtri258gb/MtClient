Code Notebook

Component <code-notebook> viết bằng vanilla JS (Custom Element + Shadow DOM), có thể nhúng vào bất kỳ file index.html nào chỉ bằng một thẻ <script>. Mỗi cell chọn được ngôn ngữ, gọi API tự custom để thực thi (cmd / js / python / duckdb), và cho phép gắn thêm tool riêng theo từng cell.

Demo này dùng một bộ thực thi giả lập ngay trên trình duyệt (xem hàm mockExecute bên dưới) để chạy được mà không cần backend thật. Trong dự án thật, chỉ cần đổi apiUrl: '/api/execute' trỏ tới API của bạn theo đúng hợp đồng nêu trong code-notebook.js.
